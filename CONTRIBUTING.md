# Contributing to V-Astra Token Optimizer

Contributions are welcome.

## Development principles

- Prefer measurable improvements over speculative complexity.
- Add tests for behavior changes.
- Do not sacrifice critical-context preservation for token savings.
- Keep provider-specific integrations isolated from the core engine.
- Document new optimization strategies.

## Before opening a pull request

- Run the test suite.
- Add or update benchmarks when changing optimization behavior.
- Explain expected token savings and retention impact.
- Confirm that fallback behavior remains safe.
